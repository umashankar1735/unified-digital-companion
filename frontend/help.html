🚀 Getting Started

What is UDC System?

The Universal Digital Campus (UDC) is an intelligent question answering system that provides accurate responses for:

  • Legal Awareness: Indian Penal Code (IPC) sections, legal procedures, and case law
  • University Support: Campus facilities, academic policies, hostel information, and administrative procedures

System Architecture

UDC uses a dual-module RAG (Retrieval-Augmented Generation) architecture:

  1. Intent Routing: Automatically classifies queries as legal or campus-related
  2. Legal Module: Uses fine-tuned InLegalBERT for legal question answering
  3. University Module: Employs hybrid retrieval (BM25 + FAISS) with T5 generation
  4. Response Generation: Produces grounded answers with source attribution

📖 User Manual

How to Use Legal Awareness Module

  1. Navigate to Legal Awareness page
  2. Enter your legal query in the text area (e.g., "What is Section 302 IPC?")
  3. Optionally select a category (Procedural, Substantive, Criminal, Civil)
  4. Click "Submit Query" button
  5. View results table with ranked answers, categories, and confidence scores
  6. Review criminal warning if your query contains keywords like "murder", "theft", etc.

How to Use University Support Module

  1. Navigate to University Support page
  2. Enter your campus-related query (e.g., "What are hostel check-in times?")
  3. Select category: Academic, Hostel, Library, Sports, Medical, or Administrative
  4. Click "Submit Query" button
  5. View hybrid retrieval results with relevance scores
  6. Results are color-coded: Green (>85%), Yellow (70-85%), Red (<70%)

❔ Frequently Asked Questions

Q1: What types of legal questions can I ask?

You can ask about IPC sections, legal procedures, criminal law, civil law, and case-related queries. The system is trained on 9,763 legal QA pairs covering Indian legal framework.

Q2: How accurate are the answers?

Legal module achieves 99.6% Exact Match accuracy, and University module achieves 66.5% EM with 77.6% F1. Both modules have 0% hallucination rate, ensuring factual responses.

Q3: What does "Grounding: 100%" mean?

It means every answer is grounded in the source dataset. The system never fabricates information - all responses are derived from verified QA pairs.

Q4: Why am I seeing a criminal warning?

If your query contains keywords like "murder", "theft", "assault", etc., the system displays a disclaimer stating this is for educational purposes only and not legal advice.

Q5: Can I download evaluation results?

Yes! Visit the Reports page to download metrics in CSV/JSON format, complete evaluation reports in PDF, and presentation materials.

Q6: What is hybrid retrieval?

University module uses both BM25 (keyword-based) and FAISS (semantic vector search), then reranks with CrossEncoder. This combines the strengths of lexical and semantic matching.

Q7: How do I cite this system in my research?

Reference the published conference paper: "Universal Digital Campus: An Intelligent Multi-Domain Question Answering System" (CRC_587.pdf). Download citation from Reports page.

Q8: Can I add new datasets?

Yes, but requires retraining. Place new QA pairs in CSV format in the data/ folder, then run training scripts. See technical documentation for details.

🔧 Troubleshooting

Problem Possible Cause Solution
No results displayed Query too short or API error Enter at least 5 words. Check API status in Settings.
Low confidence scores Query outside training domain Rephrase query or select appropriate category.
Slow response time High server load or large result set Reduce Top-K in Settings. Check system resources.
API connection error Backend services not running Start Flask (port 5000) and FastAPI (port 8000) servers.
Missing search indices Indices not built Run: python backend/scripts/2_build_indices.py

Running Backend Services

Legal Awareness API (Flask):
cd "LEGAL AWARENESS MODULE/legal-awareness-backend" && python src/app.py

University Support API (FastAPI):
cd "UNIVERSITY SUPPORT MODULE/backend/api" && uvicorn app:app --reload --port 8000
