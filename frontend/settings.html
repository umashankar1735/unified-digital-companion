ℹ️ About This Project

Project Title: Universal Digital Campus (UDC) - An Intelligent Multi-Domain Question Answering System

Objective: To develop a comprehensive RAG-based question answering system that addresses both legal awareness and university campus support queries with high accuracy and zero hallucination.

Key Features:

  • Dual-module architecture for legal and campus support domains
  • Fine-tuned InLegalBERT model achieving 99.6% Exact Match accuracy
  • Hybrid retrieval system combining BM25 and FAISS with CrossEncoder reranking
  • Ensemble-based intent routing with 94.1% accuracy
  • Zero hallucination rate through grounded answer generation
  • Production-ready REST APIs with Docker deployment

Research Contribution: This system demonstrates that domain-specific fine-tuning combined with hybrid retrieval significantly outperforms general-purpose LLMs and baseline RAG systems in specialized QA tasks.

Publication: Conference Paper CRC_587.pdf submitted with comprehensive evaluation results.
