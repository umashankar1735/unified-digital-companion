Technical Implementation Details

Legal Module Model: InLegalBERT (Fine-tuned on 9,763 samples)
University Module Model: T5-Small + Hybrid Retrieval (BM25 + FAISS)
Reranker: CrossEncoder ms-marco-MiniLM-L-6-v2
Embedding Model: sentence-transformers/all-MiniLM-L6-v2
Training Epochs: 3 epochs with batch size 16
Evaluation Samples: 500 (Legal), 200 (University)

Key Findings

✓
Superior Performance: UDC system achieves 99.6% EM and 99.7% F1 on Legal module, significantly outperforming baseline methods (TF-IDF+BERT: 38.5% EM, End-to-End LLM: 43.8% EM).
✓
Zero Hallucination: Both modules demonstrate 100% grounding with 0% hallucination rate, ensuring reliable and trustworthy responses.
✓
Efficient Intent Routing: Ensemble-based router achieves 94.1% accuracy with only 6.2% escalation rate and 0.53s latency.
✓
Production Ready: Average response times under 500ms make the system suitable for real-time deployment.
